How to study with these

  1. Follow the order above — it mirrors the study path's session plan (messaging → databases → caching → realtime → search → blobs → streams → geo → rate limiting → distributed).
  2. Run before you read. git clone a repo, npm run phase1, watch the log, then open the phase's source — every file is a self-contained lesson ending in a takeaway.
  3. Drive the lab. npm run web opens the interactive lab; every phase is a panel whose numbers match the script's output.
  4. Drill out loud. Each lab's Drill tab holds the module's real interview questions — answer before revealing. Recall beats re-reading.
  5. Close the loop. Each repo's STUDY-GUIDE.md maps every phase to the exact study-module section and the deep dives to read next.
